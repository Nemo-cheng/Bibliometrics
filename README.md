# 传染病建模文献知识图谱：内容抽取

从传染病建模文献全文中抽取实体与关系，用于文献计量学知识图谱。

## 目录

| 路径 | 内容 |
|---|---|
| `../抽取文献/` | 原始 PDF（不在本仓库内） |
| `fulltext/` | 第 1 步输出的全文文本（不入库，可重建） |
| `01_pdf_to_text.py` | 第 1 步：PDF 转纯文本 |

## 运行

```bash
uv run --with pypdf python 01_pdf_to_text.py ../抽取文献 fulltext
```
